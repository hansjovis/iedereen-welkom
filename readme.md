# Iedereen Welkom

## Development
1. Install dependencies
    ```
    npm install
    ```
2. Run tests (with code coverage)
    ```
    npm run test
    ```
3. Run linting
    ```
    npm run lint
    ```
4. Run Nest server in dev mode
    ```
    npm run dev
    ```
5. Test authorization flow by following this link:
    http://localhost:3000/authorize?client_id=d83eec13-bf8e-4439-81eb-fd4128d2cd72&response_type=code&scope=openid%20email&redirect_uri=http%3A%2F%2Flocalhost%3A1234%2Flogin
