# Iedereen Welkom

## Development
1. Install dependencies
    ```
    npm install
    ```
2. Run tests (with code coverage)
    ```
    npm run test
    ```
3. Run linting
    ```
    npm run lint
    ```
4. Build TypeScript
    ```
    npm run build
    ```
